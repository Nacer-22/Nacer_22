# تقرير حالة البناء — HAX SHOOTING 0.3.0-alpha

## فحوص محلية
- `node --test test/*.test.js`: 7 اختبارات ناجحة، صفر فشل.
- `node --check src/index.js`: فحص تركيب JavaScript ناجح.
- فحص GLB: تسعة نماذج قابلة للفتح؛ كل مشغّل يحتوي على 62 قطعة هندسية.
- فحص PBR: أربع مجموعات Albedo بدقة 2048×2048 وخرائط Normal/Roughness/AO بدقة 1024×1024.
- الحجم المصدر المحلي يقارب 28 MiB.

## ما لم يُختبر
- Godot headless غير متاح محلياً، لذلك لم يُجر parser/import أو اختبار مشهد 3D هنا.
- Android SDK/Gradle غير متوفرين؛ لم ينتج APK ولم يُختبر على هاتف.
- خادم الغرف غير منشور؛ حد موارد Railway المجاني منع إنشاء مشروع جديد. لم تُعدّل الخدمات الحالية.
- لم يُختبر LAN أو الإنترنت على جهازين فعليين.

## قيود الجودة
نماذج المشغلين ثابتة وليست Skeletal rigs. الأصوات مولدة إجرائياً. الخرائط إجرائية وليست عوالم AAA يدوية. المشروع Alpha وليس إصداراً تجارياً مكتملاً.
