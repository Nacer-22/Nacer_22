# نشر خادم HAX SHOOTING على Railway

الخادم منفصل عن تطبيق Android. لا تضعه في نفس خدمة بوت HAX أو خادم الاشتراكات.

## الإعداد
- اربط مستودع اللعبة بفرع hax-shooting-dev.
- أنشئ خدمة جديدة عندما تتوفر حصة موارد Railway.
- اجعل Root Directory للخدمة: HAX_SHOOTING_NATIVE/server.
- استخدم Dockerfile وrailway.json الموجودين في المجلد.
- أنشئ Public Domain للخدمة؛ التطبيق يستمع إلى المنفذ PORT الذي تحدده Railway.
- بعد نجاح النشر، تحقق من /health ثم استخدم العنوان wss://DOMAIN/ws في إعداد المشروع hax/online_server_url قبل تصدير APK.

## حدود خادم Alpha
الغرف وحالة اللاعبين محفوظة في الذاكرة؛ إعادة تشغيل الخدمة تمسح الغرف. لا توجد حتى الآن حسابات موثقة أو قاعدة بيانات للمخزون والنتائج أو matchmaking موزع أو حماية تنافسية كاملة. لا تستخدمه لمباريات Ranked العامة قبل إضافة Line-of-Sight ومصادقة وتخزين ومراقبة واختبار ضغط.

## قيد Railway
محاولة إنشاء مشروع مستقل أثناء إعداد الحزمة رُفضت بسبب تجاوز حد توفير الموارد في الخطة. لم يتم تعديل أي خدمة قائمة أو متغيرات أو تخزين لمشاريع HAX الأخرى.
