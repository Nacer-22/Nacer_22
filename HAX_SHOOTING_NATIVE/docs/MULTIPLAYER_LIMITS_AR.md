# حالة أنظمة اللعب الجماعي

## Online
خادم Node.js/WebSocket ينشئ الغرف، يقبل رمز الغرفة، يبث اللقطات والدردشة ويفحص حدود الحركة ومعدل الإطلاق وحساب إصابة أولي. حالة الغرف محفوظة في الذاكرة فقط. يحتاج رابط WebSocket منشوراً.

## LAN
يستخدم ENet عبر UDP ويمكنه مزامنة position/yaw/pitch وعرض المشغلين الآخرين. هذه مزامنة حركة أولية وليست محاكاة مباراة سلطوية كاملة. لا تنتقل بعد جميع حالات البوتات والنتائج والمخزون بشكل متزامن.

## Bluetooth
غير منفذ؛ يحتاج Android native plugin واختباراً فعلياً للاقتران والاتصال وصلاحيات Android.

## قبل الإصدار التنافسي
المطلوب: مصادقة وحسابات، خادم authoritative كامل، line-of-sight، تخزين دائم، rate limits موزعة، مراقبة، مكافحة غش واختبارات ضغط وNAT.
