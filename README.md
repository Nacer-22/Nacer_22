# Nacer_22 server configurations

This repository contains the valid JSON configurations extracted from the uploaded archive.

## Import into Happ

Use one of the raw JSON file URLs as a standard subscription URL:

- `subscribtion.json` — SOCKS outbound configuration.
- `subujghkk.json` — Hysteria v2-style configuration.

The original `Nacer.json` was not included because it contains malformed JSON and cannot be imported as-is.

**Privacy:** this repository is public. The configuration files contain server addresses and authentication credentials. Anyone with access to the repository can read and copy them.
