# Nacer_22 server configurations

The repository contains two valid JSON proxy profiles from the uploaded archive.

## Happ subscription

Use this combined standard subscription URL:

`https://raw.githubusercontent.com/Nacer-22/Nacer_22/main/subscription.json`

It contains both configurations:
- `Nacer_22` — SOCKS outbound with routing rules.
- `Nacer_22 Hysteria` — Hysteria v2-style outbound.

The individual source files are also available as `subscribtion.json` and `subujghkk.json`.

The original `Nacer.json` was not imported because its first inbound entry is malformed JSON.

**Privacy:** this repository is public. The JSON files include server addresses and authentication credentials, so anyone who can access the repository can read and copy them.
