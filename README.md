# Nacer_22 server configurations

This repository contains three valid JSON proxy profiles extracted from the uploaded archive. The malformed inbound entry in the original `Nacer.json` was repaired using the same SOCKS inbound settings present in the other supplied configs; its original outbound server credentials were preserved.

## Happ subscription

Use this combined standard subscription URL:

`https://raw.githubusercontent.com/Nacer-22/Nacer_22/main/subscription.json`

It contains three profiles:
- `Nacer_22` — SOCKS outbound with routing rules.
- `Nacer_22 Hysteria` — Hysteria v2-style outbound.
- `Nacer_22` — the repaired SOCKS outbound profile.

Individual JSON files are also available: `Nacer.json`, `subscribtion.json`, and `subujghkk.json`.

**Privacy:** this repository is public. The JSON files include server addresses and authentication credentials, so anyone who can access the repository can read and copy them.
